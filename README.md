# 🌌 Sistema Solar 3D con Three.js

Este proyecto es una simulación visual del Sistema Solar creada con **Three.js**, donde cada planeta orbita alrededor del Sol y cuenta con lunas animadas que giran alrededor de cada planeta.

La animación se renderiza en tiempo real usando WebGL directamente en el navegador.

---

## 🚀 Características principales

- Simulación completa del Sol y los planetas.
- Lunas con órbitas individuales.
- Tamaños y colores configurables.
- Animación fluida mediante `setAnimationLoop`.
- Código optimizado usando funciones y estructuras de datos organizadas.

---

## 🛠️ Tecnologías utilizadas

- **Three.js**
- **JavaScript**
- **HTML**
